# Web Frontend (`apps/web`)

Control plane web application for the Single-Pass 3D Reconstruction Platform.

## Stack
- **Framework:** Next.js 16 + TypeScript
- **3D Geospatial Engine:** CesiumJS
- **Styling:** Tailwind CSS + Radix UI Primitives
- **Brand Palette:** Bubblegum Pink (`#FF69B4`), Deep Teal (`#069494`), Electric Cyan (`#00F0FF`), White (`#FFFFFF`)
- **Authentication:** Auth0 React SDK
